# AI & Automation Experiments

This repository contains personal projects exploring applied AI, machine learning, Agentic AI and intelligent automation.  
The focus is on building systems that can interact with APIs, enterprise data sources, and real-world workflows.

These projects complement my work in enterprise integration by exploring how AI agents and predictive models can integrate with API-driven systems.

---

## Projects

### 1. Transaction Anomaly Detection (Machine Learning)
A machine learning project that detects anomalous transaction patterns using structured financial datasets.

Key components:
- Data preprocessing and feature engineering
- Handling imbalanced datasets
- Model comparison (Logistic Regression, Random Forest, XGBoost)
- Evaluation using classification metrics

Goal:
Explore how anomaly detection models could support fraud monitoring or automated decision workflows in enterprise systems.

---
### 2. Brain Tumor Detection (Computer Vision)

A deep learning project for detecting brain tumors from MRI images using convolutional neural networks and transfer learning techniques.

Key elements:
- Image preprocessing and augmentation
- CNN-based classification model
- Transfer learning using EfficientNet
- Model evaluation and visualization techniques such as Grad-CAM

Objective:  
Explore computer vision techniques for medical image classification and understand how deep learning models can extract patterns from complex visual datasets.

### 3. Natural Language Weather Agent (AWS)
An AI agent capable of interpreting natural language weather queries and retrieving weather data through APIs.

Features:
- Natural language interaction
- API orchestration
- Agent workflow using AWS services

Goal:
Demonstrate how AI agents can interact with APIs to automate tasks.

---

### 4. SBA RAG System with AI Agent - Small Business Administration Q&A Assistant
A Retrieval-Augmented Generation (RAG) system enhanced with AI agent capabilities that provides accurate, verified answers about SBA loans, certifications, and business resources by retrieving information from official SBA documentation and performing financial calculations.

Features:
- Document ingestion
- Embedding generation
- Semantic search
- Context-aware responses
- Multi-tool reasoning and orchestration
-Loan payment calculator (precise amortization formula)
-Autonomous tool selection based on question type

Goal:
Explore how enterprise knowledge bases can power AI assistants and automated workflows.
